## 发现项（非缺陷，产品增强建议）

1. **E06 语义**：`GET /conversations/{未知id}/messages` 返回 `200 + []`（查询语义）。
   更 REST 的做法是 404（会话本身不存在）。评分：P3 体验项。
2. **G04 语义**：评测结果 `hit` 在未填 `expected_doc_name` 时为 `null`（设计如此，
   `check_hit` 文档注明）。前端展示时需区分「未测」与「未命中」。评分：P3 前端注意项。
3. **首轮用例侧踩坑**（已修正，记录供后来者）：openapi 路径是 `/api/openapi.json`；
   Qdrant 集合名去横线 `nexusrag_kb_{kb_id不带横线}`；eval 分数为 float。
